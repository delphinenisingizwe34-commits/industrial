CURRENCY EXCHANGE APPLICATION

This website is a currency exchange application.
it helps user convert money from one currency to another,like from Rwandan Francs(RWF) to US Dollars(USD) or Euros(EUR).
The system has different pages:
-Home page:shows a quick converter and basic information
- Converter page:Allows full currency conversion
- Details page:show information about currencies
- History page:saves previous conversions
- Setting page:Lets user change theme (dark/light mode)
